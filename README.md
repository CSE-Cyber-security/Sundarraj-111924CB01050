# Cybersecurity Asset Inventory System

## Weekly Mini Project – 01

A Python-based Cybersecurity Asset Inventory System for managing an organization's IT assets.

## Features

- Add assets
- Display all assets
- Search assets
- Update assets
- Delete assets
- Generate security summary

## Asset Information

The system stores:

- Asset ID
- Asset Name
- Asset Type
- IP Address
- Operating System
- Department
- Risk Level
- Security Status

## Asset Types

- Workstation
- Server
- Router
- Switch
- Application

## Risk Levels

- Low
- Medium
- High
- Critical

## Security Status

- Secure
- Warning
- Vulnerable

## Technologies

- Python 3
- JSON
